# 官方偏好可学性诊断 (2026-09-08)

**问题**: 官方相对我们公式的残差, 用 ML 是否可学? 决定是否值得上 LTR / 特征扩容.

**方法**: 254 赛事全 raw 选手 15811 行 × 32 特征样本集 (`tuning/learn/dataset.pkl`),
LightGBM + GroupKFold **按赛事切** (5 fold, 训练不含验证赛事任何官方信息 = 模拟预测未见赛事).
标签 y=官方名单成员 (1791 正, 与生产 in_tot 完全一致). 特征组:
  RAW 19 维单图聚合 / BL 3 维 baseline(公式外字段) / FM 9 维公式中间量 / TS 公式总分.
生成: `tuning/learnability_export.py` + `tuning/learnability_diag.py`, OOF proba 在 `tuning/learn/oof_probas.pkl`.

## 结果 (in_topn 口径 = 每赛事 OOF 排名 top N 与官方交集, 与生产 86.32% 同口径)

| 模型 | AUC全池 | AUC边界池 | in_topn | mvp top1 |
|---|---|---|---|---|
| 公式 (生产对照) | - | - | **86.32%** | **80.31%** |
| M0 仅公式分 | 0.967 | 0.902 | 84.02% | 77.6% |
| M1 RAW 原始输入 | 0.980 | 0.934 | 85.08% | 69.3% |
| M2 RAW+BL (公式外 baseline) | 0.983 | 0.942 | 85.77% | 68.5% |
| M3 全特征 RAW+BL+FM+TS | 0.984 | 0.947 | **86.04%** | 67.3% |
| MVP 专项 @FULL (学 is_mvp) | 0.991 | - | - | 75.2% |

## 结论

1. **现有字段上残差不可学**: M3 把公式全部中间量+原始输入+公式外字段都给 GBDT,
   赛事级 OOF in_topn 86.04% 仍**反超不了公式 86.32%**. MVP 维度单独建模 75.2% 也低于公式 80.31%.
2. **公式 ≈ 现有字段可学上界**: M1(纯原始输入)85.08% 已逼近, 说明 42 参数公式把输入信息几乎全部编码;
   M0 仅 84% 额外证明"跨赛事统一校准公式分"会因年代 cut 线漂移掉 ~2pp.
3. **公式外客观字段有效但现缺**: 本地唯一公式外字段 baseline 族带来一致小幅提升
   (M2 vs M1: 边界 AUC 0.934→0.942, in_topn +0.7pp) → **证明给模型新客观字段有真实回报**,
   只是本地这一个字段太弱, 叠加几个真正的公式外字段 (HLTV rating2.0/impact/KAST/ADR/clutch)
   才有望实质性反超公式.
4. 主观叙事残差 (MVP ~25%、EVP 名单内错位) 不可学 — 任何方法到不了 100%.

**决策**: 不上 LTR / 不加字段的残差模型 → 期望收益 ≈0 (M3 已证). 唯一通路 = 采集公式外客观字段.
